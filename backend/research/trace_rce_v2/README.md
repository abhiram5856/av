# TRACE-RCE v2 — Trainable Multimodal Root Cause Engine

TRACE-RCE v2 (Temporal-Relational Adaptive Causal Explainer - Version 2.0) is a trainable machine learning model for plant disease root-cause attribution. It consumes the multi-modal `AIContext` objects generated by the NOVA v2.0 pipeline and ranks the most likely underlying root causes of crop failure.

Unlike TRACE-RCE v1 (which uses hand-tuned rule-based weights and thresholds), v2 is a **fully trainable PyTorch model** that automatically learns feature representation, cross-modal interactions, ranking scores, and probability calibration from historical data.

## Technical Architecture

### 1. Modality Encoders
We project each modality’s raw feature vector into a shared embedding space ($d=32$):
$$\mathbf{h}_m = \text{LayerNorm}(\text{GELU}(\mathbf{W}_m \mathbf{x}_m + \mathbf{b}_m)) \in \mathbb{R}^d$$
This maps visual, weather, severity, knowledge, and historical signals to compatible semantic spaces.

### 2. Cross-Modal Attention
Modality embeddings are stacked into a sequence $\mathbf{H} \in \mathbb{R}^{5 \times d}$ and processed using Multi-Head Self-Attention ($H=2$ heads). This allows modalities to attend to one another to resolve ambiguities or missing data:
$$\mathbf{A} = \text{softmax}\left(\frac{\mathbf{Q} \mathbf{K}^T}{\sqrt{d_k}}\right)$$
$$\mathbf{H}' = \text{LayerNorm}(\mathbf{H} + \text{Dropout}(\mathbf{A}\mathbf{V}))$$
The $5 \times 5$ attention matrix $\mathbf{A}$ is extracted directly for modal-level explainability.

### 3. Cause-Conditioned Ranking
We define learnable embeddings $\mathbf{e}_j \in \mathbb{R}^d$ for each of the 13 causes. The pooled context $\mathbf{z} = \text{MeanPool}(\mathbf{H}')$ is compared with $\mathbf{e}_j$ through element-wise interaction:
$$s_j = \text{MLP}([\mathbf{z}; \mathbf{e}_j; \mathbf{z} \odot \mathbf{e}_j]) \in \mathbb{R}$$
The scores are sorted descending to rank the causes.

### 4. Vectorized ListMLE Loss
Optimizes the ranking likelihood of the correct causes sequence $\pi^*$ directly:
$$\mathcal{L}_{\text{ListMLE}} = \sum_{i=1}^{N-1} \left( \log\sum_{j=i}^{N} \exp(s_{\pi^*(j)}) - s_{\pi^*(i)} \right)$$

### 5. Temperature-Scaled Calibration
Probability confidences are calibrated using a learnable temperature parameter $T > 0$:
$$p_j = \sigma\left(\frac{s_j}{T}\right)$$
$$\mathcal{L}_{\text{Brier}} = \frac{1}{N} \sum_{j=1}^{N} (p_j - y_j)^2$$
$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{ListMLE}} + 0.3 \cdot \mathcal{L}_{\text{Brier}}$$
