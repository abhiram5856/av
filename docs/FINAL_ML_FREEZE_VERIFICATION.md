## SECTION 13: Remaining Limitations

1. **PlantVillage Domain Gap**: All training images are lab-segmented with white/black backgrounds. Real-world crop photography will degrade accuracy.
2. **Visual Branch Marginality in ECE**: Removing or corrupting visual features produces a max Δ P@1 of 0.0994. The ECE does not demonstrably rely on visual features.
3. **Synthetic ECE Training**: Ground-truth causal labels are heuristic, not field-validated. Evaluation is on the same distribution.
4. **Small Per-Class Test Sets**: Classes like `cherry_leaf` and `corn_gray_leaf_spot` have <10 test samples — metrics for these classes are statistically unreliable.
5. **Non-Stratified Vision Split**: `random_split()` is not stratified; rare classes may be underrepresented in test.
6. **Calibration**: Vision ECE=0.0556, ECE model ECE=0.3295. Both models are overconfident.
7. **No Pixel-Level Robustness**: Feature-space perturbation ≠ pixel-level noise robustness.
